# IBI WebFOCUS MCP Server Extension

This extension hosts an MCP server for interacting with IBI WebFOCUS.

## Usage

1. Configure your WebFOCUS credentials in settings (`webfocus.baseUrl`, `webfocus.username`, `webfocus.password`).
2. Run the command **IBI WebFOCUS: Start MCP Server**.
3. Connect your MCP client (like a Python agent or Claude Desktop) to this server via Stdio.
